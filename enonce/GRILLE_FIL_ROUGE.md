# Grille d'évaluation — Cas fil rouge (rendu de groupe, sur 20)

| Critère | Points | Attendus pour la note maximale |
|---|---:|---|
| **1. Profilage et qualité des données** | 3 | Anomalies documentées par source ; une règle explicite pour chacune (rejet, correction, signalement) |
| **2. Collecte asynchrone** | 3 | Collecteur OpenAgenda complet : pagination par curseur, fenêtres en parallèle, retries, reprise |
| **3. Nettoyage et chargement** | 3 | Tests fournis au vert + 3 tests ajoutés ; dédoublonnage, rapprochement des lieux ; chargement idempotent |
| **4. SQL avancé et optimisation** | 4 | Q1-Q4 et R1-R4 corrects ; une optimisation EXPLAIN chiffrée avant / après |
| **5. Indicateur** | 3 | Indice conforme à la méthode, top 10, couverture ; limites clairement énoncées |
| **6. Industrialisation et publication** | 2 | Logs, quarantaine, contrôles bloquants ; dataset tagué sur le Hub, Dataset Card générée |
| **7. Restitution orale** | 2 | Démo fluide, choix justifiés, chaque membre répond à une question |
| **Total** | **20** | |

**Malus** : jeton commité (−2) ; pipeline non exécutable en suivant le README (−3).
**Bonus (+1 max)** : Lovélo ou ponctualité Astuce intégrés à l'analyse ; météo comme variable de contrôle.
Note individuelle : la note de groupe peut être modulée (±2) selon la maîtrise montrée aux questions.
